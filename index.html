The big bitter lesson question in the applied AI layer is that as models get better and better, what is the best way to diffuse that intelligence into an enterprise. Ironically, I'd argue that as models are getting more capable, and can handle longer running tasks and better tool use, the ability to differentiate on a domain by domain basis goes up instead of down. When models were quite limited in what they could do, ironically all you could be literally was a "wrapper" because you were effectively delivering tokens back to the user with a custom prompt or some limited RAG. But in a world of agents using tools, tasks that run on for hours or days, workflows that kick off agents, agent swarms that need to be coordinated against a goal, data sources that are domain specific, model routing that requires domain-specific routing, implementation that requires real change management of the workflow instead of "just type into this chat box", it's very very possible that specialization of these systems goes up more. Obviously this doesn't apply to everything - the closer you are to the labs core use-cases the tougher this play gets, but I'd argue we're going to see autonomous systems for a wide range of job functions that weren't practical to build out before. We'll see this in security, life sciences, healthcare, finance, manufacturing, and many other fields. Either way going to be a fun and wild couple of years.
在应用 AI 层，"苦涩的教训"式的大问题在于：随着模型越来越强，把这种智能扩散进企业的最佳方式是什么？ 讽刺的是，我认为随着模型能力提升、能处理更长的任务和更好的工具调用，按领域进行差异化的能力反而在上升，而不是下降。 当模型能力还相当有限时，讽刺的是你唯一能做的就是当个"套壳"——因为你本质上只是用自定义提示词或有限的 RAG，把 tokens 转发回用户。 但在一个由智能体使用工具的世界里：任务会持续数小时甚至数天，工作流会触发智能体，智能体集群需要围绕目标协调，数据源是领域专属的，模型路由需要领域专属的路由，落地实施需要真正的工作流变革管理而非"往聊天框里打字"——这些系统的专业化程度非常可能进一步提升。 显然这并不适用于所有场景——越靠近实验室核心用例的地方，这种打法越难。但我认为我们会看到面向广泛职能的自主系统，而这些在过去是不具备可行性去构建的。我们会在安全、生命科学、医疗、金融、制造等众多领域看到它。无论如何，接下来几年都会很有趣也很狂野。

Truth be told, I was one of the early users of Wabi 1.0 and while the design was gorgeous, it frankly never "stuck" with me. But, in moments of downloading this edition, I was immediately hooked. It just gets the "paradigm" right imo. There are two types of personal agents today: 1) Singleplayer iMessage or Muse types - while useful it's hard to compartmentalize them when many things are going on 2) Build your own multiple chat Hermes agents - while that's useful and can share context, they live forever Wabi has this great paradigm of orchestrator (which is the main agent) and topic specific episodic chats that are for a single purpose. My only critique so far it's TOO proactive, the apps can be better and they need to dial both of those in, but this is a wonderful product that everyone should try!

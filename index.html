New research from Replit on scaling laws for agent swarms. We show that scaling the number of agents can yield dramatic performance gains, but unlike traditional scaling laws, more compute doesn't necessarily translate into better results, and how agents organize themselves matters. - Given a fixed two-hour window, Opus 5.5 went from a 3.7x speedup on NumPy with one agent to 18.9x with 32 agents. - GPT-6.2 Astra was the strongest solo agent but exhibited negative scaling beyond 8 agents. - Models spontaneously developed different organizational structures. Decentralized swarms scaled better than those that relied on centralized coordination. - The parallelizability of the problem was a strong predictor of swarm performance. - Interestingly, individual model intelligence is a poor predictor of collective intelligence. We're also open-sourcing Optimization-Bench to advance research into this new dimension of inference-time scaling.
Replit 关于 Agent 集群扩展定律的新研究。 我们表明，扩展 Agent 数量可以带来显著的性能提升，但与传统的扩展定律不同，更多算力并不必然转化为更好的结果，而且 Agent 如何组织自身至关重要。 - 在固定的两小时窗口内，Opus 5.5 在 NumPy 任务上从单 Agent 的 3.7 倍加速，提升到 32 个 Agent 时的 18.9 倍。 - GPT-6.2 Astra 是最强的单 Agent，但在超过 8 个 Agent 后出现负向扩展。 - 模型自发演化出不同的组织结构。去中心化集群的扩展效果优于依赖集中式协调的集群。 - 问题的可并行性是集群性能的有力预测指标。 - 有趣的是，单个模型的智能水平并不能很好地预测集体智能。 我们还将开源 Optimization-Bench，以推进这一推理时扩展新维度的研究。

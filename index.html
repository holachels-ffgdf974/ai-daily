@box CEO —— 你的业务存在于内容之中，用 AI 释放它的价值

Personal agents are the ultimate manifestation of "build something that agents want". The form factor of a product like Muse is you want to be able to hand off a task to the agent and ensure that it is fully completed end to end. To do this, the agent must be able to successfully operate with your tools or use its own to complete the task. Use your MCP or CLI, easily navigate your site, be able to transact, and more. The new attention you need to compete for is not from the user itself but instead for the agent. This means that the tools that allow agents to order food, handle ecommerce transactions, book flights, work with the local economy, and interact with our data and information best, are the ones that will get used the most. This will ultimately be the biggest opportunity and shakeup in consumer tech since the App Store itself.

个人 Agent 是"打造 Agent 想要的东西"这一理念的终极体现。 像 Muse 这类产品的形态意味着，你希望能把一项任务交给 Agent，并确保它端到端地彻底完成。要做到这一点，Agent 必须能够顺利地调用你的工具，或使用它自己的工具来完成任务：使用你的 MCP 或 CLI、轻松浏览你的网站、完成交易，等等。 你如今需要争夺的新"注意力"，不再来自用户本身，而是来自 Agent。这意味着，那些能让 Agent 最好地点外卖、处理电商交易、预订机票、参与本地经济、并与我们的数据和信息交互的工具，将会被使用得最多。 这最终将成为自 App Store 问世以来，消费科技领域最大的一次机遇与洗牌。

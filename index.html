There are massive startup opportunities hiding in plain sight : every layer of the computing stack will need to be rebuilt for agents. For the last few years, most of the focus has been on making enterprise software agent-ready: APIs, connectors, MCPs. Now personal agents are forcing the same conversation for consumer products - e-commerce is an early example. This is just the tip of the iceberg. Now think about the rest of the stack: Desktop and mobile OSes where agents are first-class users Cloud infra built for agents to operate directly. identity, permissions and security designed for thousands of agents acting on our behalf. Interfaces designed for agent and human users or both working together. If you're looking for startup ideas, go through each layer of the computing stack and ask: what has to change when the primary user is an agent?

巨大的创业机会正藏在众目睽睽之下：计算技术栈的每一层，都将为 Agent 而重建。 过去几年，大部分注意力都放在让企业软件「为 Agent 做好准备」上：API、连接器、MCP。 如今，个人 Agent 正在把同样的讨论推向消费级产品——电商只是一个早期的例子。 而这仅仅是冰山一角。 再想想技术栈的其余部分： 桌面与移动操作系统，Agent 成为一等公民用户； 为 Agent 直接运行而构建的云基础设施； 为成千上万个代表我们行动的 Agent 而设计的身份、权限与安全体系； 为 Agent、人类用户，或两者协同工作而设计的交互界面。 如果你正在寻找创业点子，就逐层审视计算技术栈，然后问自己：当主要用户变成 Agent 时，什么必须改变？

This sounds weird, but it is actually probably a good policy. Anthropic may have more extreme beliefs than this (though even if they didn't, you may want to word policies like this), but this is sort of an easy Pascal's wager for AI. Just be nice to the AI.
